# Afuye Oluwotobiloba Precious — Student Portfolio

A responsive, multi-page student portfolio and academic planner built with HTML5, CSS and vanilla JavaScript.

## Pages
- `index.html` — introduction and selected demonstrations
- `about.html` — education, interests, learning map and HTML table
- `projects.html` — three sample projects with original SVG images
- `planner.html` — add, edit, complete, filter and delete academic tasks
- `contact.html` — validated front-end contact form
- `demos/` — three project demonstrations

## Function boundaries
- Planner data is stored in this browser only using localStorage. There is no login, cloud sync or online backup.
- The contact form trims and validates input but never transmits or stores a message.
- The store demonstration has a temporary sample cart only. No checkout or payment.
- The cloud-security demonstration is educational and does not monitor real infrastructure.
- Social account links remain placeholders until genuine URLs are supplied.
- The audio recording has not been supplied. See `audio/README.md`.
- No grades, certificates, awards or unprovided achievements have been invented.

## Design and responsive review targets
Test at 360px, 768px and 1440px. Check no horizontal overflow, readable type, consistent navigation, usable controls, proportional imagery, visible focus and footer placement.
